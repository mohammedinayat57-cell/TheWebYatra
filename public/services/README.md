# Service Images

Place your service images here with the following names:

1. **web-development.jpg** - Web development service image
2. **crm-solutions.jpg** - CRM solutions service image  
3. **app-development.jpg** - App development service image

## Recommended Image Dimensions
- Width: 800px - 1200px
- Height: 600px - 900px
- Format: JPG or PNG
- Aspect Ratio: 4:3 or 16:9

## Where to Get Images
See the main `IMAGE_GUIDE.md` in the project root for direct links to free, high-quality images.

### Quick Links:
- **Unsplash**: https://unsplash.com
- **Pexels**: https://www.pexels.com

Both platforms offer free, commercial-use images with no attribution required.
