## How to Add Images

### Option 1: Add to public folder
1. Download images from the sources above
2. Save them in `public/services/` folder:
   - `web-development.jpg`
   - `crm-solutions.jpg`
   - `app-development.jpg`

### Option 2: Use image URLs directly
Add `image` property to each service in `src/lib/data.ts`:

```typescript
{
  id: "web-development",
  icon: "💻",
  title: "Web Development",
  image: "/services/web-development.jpg", // Add this line
  description: "...",
  ...
}
```
